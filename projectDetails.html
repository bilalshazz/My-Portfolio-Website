DayTrack

DayTrack is a simple to use project that allows users to organise and manage their weekly tasks.

View Project on GitHub

01. About This Project

DayTrack is a weekly task organiser developed using Python. The purpose of this project is to help users manage their tasks throughout the week. DayTrack allows users to add tasks to any day from Monday to Sunday, view their tasks for a specific day and remove individual tasks, or all of them, when no longer needed.

The program also includes features such as input validation, task management and the ability to clear all tasks at once. The program keeps on running until the user ends it, after which all tasks are cleared. The main purpose of this project was mainly focused on self learning, not to develop something that could be used by everyone. I wanted to develop my Python skills with something challenging. However, I could improve this project in the future by storing all the data and ensuring users can save their tasks.

03. DayTrack Features

Add Tasks

Users can add tasks to any day of the week.

Remove Tasks

Users can remove tasks from any day of the week.

View Tasks

Users can view the tasks assigned to a specific day.

Clear All Tasks

Users can delete all tasks from across the entire week.

Day Selection

Users can select a day using its name or menu number.

Input Validation

The program checks user input and handles invalid choices.

04. Challenges & Solutions

Managing Tasks Across Multiple Days

Challenge: One challenge I encountered was organising tasks across all seven days of the week while keeping each day's tasks separate.

Solution: I created a separate list for each day and used a list to store all seven days' task lists, which allows me to manage them more easily.

Adding and Removing Tasks

Challenge: Another challenge was allowing users to add a task to their chosen day and remove specific tasks without affecting other tasks.

Solution: I used the append() method to add tasks and pop() to remove a selected task using its position in the list.

Handling User Input

Challenge: I also had to handle invalid user inputs, such as entering letters instead of numbers when selecting a task.

Solution: I used input validation checks, such as isdigit(), to ensure users enter valid options before performing an action.

Managing Empty Lists

Challenge: I had to make sure the program could handle days that had no tasks without causing errors when users tried to view or remove tasks.

Solution: I added checks to determine whether a day's task list was empty before displaying or removing tasks.

Clearing All Tasks

Challenge: I had to create an option that allowed users to clear all tasks at once without having to do that individually.

Solution: I added a confirmation step so users could choose whether to proceed with deleting all tasks or cancel the action. This helped to ensure users didn't accidentally delete all the tasks.

05. What I Learnt by Developing DayTrack

Developing DayTrack was a challenging but enjoyable experience. It helped me understand different ways of organising and managing data in Python. I gained a better understanding of how lists can be used to store and manage data, especially when working with different lists for each day of the week. I also learnt how to use list methods to perform different operations on stored data.

nexBank

nexBank is a simple to use banking application that simulates a real banking app, with the purpose of giving users a fun and realistic banking experience.

View Project on GitHub

01. About This Project

nexBank is a banking application designed to make everyday banking an easier and more enjoyable experience. The purpose of this project is to simulate a real banking system where users can perform a variety of tasks including depositing and withdrawing money, check their balance, transfer money to other people using their unique user ID, and it also includes a signup / login feature that gives users privacy and access to their account only.

The signup / login is backed by input validation, where the program checks if the username and password meet the requirements. After users create an account, they are also given a unique user ID which is randomly generated by the program. The program also includes functions, file handling, and managing data within a banking application. Within the app, there is also an option that allows users to evaluate how much tax deduction should they have based on their income, for the tax year 2026/27.

03. nexBank Features

Account Registration

Users can create an account with username and password validation, and once the account is created they will also be assigned a unique randomly generated user ID.

Login Authentication

Users have up to five login attempts, after which access to their account will be denied if verification fails.

Deposits, Withdrawals & Transfers

Users can deposit, withdraw and transfer money with checks for valid amounts, insufficient funds and verification of user ID.

Data Management

Account information and balances are securely stored in a CSV file, ensuring that all data remains stored and available even after the program is closed.

Balance Management

Users can check their balance and keep track of available funds, and any changes to their balance will also be updated in the CSV file.

Income Tax Calculator

Users can estimate how much tax they should pay for the tax year 2026/27 based on their income.

04. Challenges & Solutions

Input Validation

Challenge: To ensure the program was a success I had to handle invalid usernames, passwords, transaction amounts and user input. This was a must to make sure the program actually simulates a real banking app.

Solution: To solve this challenge I added some input validation checks to make sure users enter valid information before they can continue.

User Authentication

Challenge: Another challenge I faced while developing the program was ensuring users could only access their own accounts, and I also had to deal with incorrect login details.

Solution: The solution for this challenge was to check the user input for login details against the ones stored in the CSV file, with a limit of five login attempts.

Random User ID

Challenge: Another challenge was to create a random user ID for every new account, making sure that each user could be identified separately within the program. This feature also allows users to transfer money between accounts.

Solution: I used a C library to generate a random six digit user ID whenever a new account was created.

Income Tax Calculation

Challenge: I also had to solve another challenge which was to implement an income tax calculator that calculates different tax bands and personal allowances.

Solution: I had to research the income tax rates for the 2026/27 tax year and then I had to implement calculations in C to estimate how much tax users would need to pay based on their income.

Managing Transactions

Challenge: Another challenge was to ensure that all deposits and withdrawals were processed correctly, preventing users from entering invalid amounts or withdrawing more money than they had available. I also had to make sure that when users transfer money to others, the user ID they entered was valid.

Solution: I solved this challenge by implementing validation checks in my program to make sure the transaction amounts were valid and that users had enough funds before they could withdraw the requested amount. I then had to make sure that the user ID entered for a transfer existed in the CSV file.

I developed this project after learning how to code in C, and the purpose of it was to strengthen my understanding of C programming, and gain some practical experience working with a large and complex application. Throughout this project I improved my knowledge and understanding of modular programming, file handling, data management through the use of CSV files, and much more. Overall, nexBank has helped me become more confident in my programming abilities using C, and gave me a better understanding of how to plan, structure and develop a complex application. secureGen

SecureGen is a random password generator developed using Python. The purpose of this program is to help users generate strong passwords.

View Project on GitHub

01. About This Project

SecureGen is a random password generator that allows users to generate a strong random password by choosing the desired length of the password, with a minimum requirement of 8 characters. The program generates random passwords with a combination of uppercase and lowercase letters, numbers and special characters.

A weak password can significantly put personal accounts and sensitive data at risk, making them more vulnerable to unauthorised access and cyberattacks, which is why I decided to develop SecureGen, helping users create stronger and more random passwords, which also improves their online security. In addition to this, another purpose of this project was to improve my Python skills and gain practical experience with string manipulation.

02. Core Concepts

Python

String Manipulation

Randomisation

ASCII

Character Sets

Exception Handling

03. secureGen Features

Input Validation

SecureGen checks that the password is at least 8 characters long.

Error Handling

The program handles invalid input, such as letters or symbols entered instead of a number, which should be greater than or equal to 8.

Character Shuffling

All the characters are randomly shuffled to create a randomly arranged password.

Character Variety

SecureGen generates random passwords that include uppercase and lowercase letters, special characters and numbers.

Password Formatting

This program also converts the list of characters that have been generated into a single string.

04. Challenges & Solutions

Password strength

Challenge: I had to make sure that every password generated by the program was strong and that it contained a variety of characters to make the password stronger.

Solution: To make sure only strong passwords were generated, I ensured that the program would include uppercase and lowercase letters, numbers and special characters in the password.

Validating Password Length

Challenge: I also had to make sure that users could only generate passwords that meet the minimum required length.

Solution: I added a validation check to make sure the password length was at least 8 characters before generating a strong random password.

Generating Random Passwords

Challenge: I had to find a way to generate random passwords using different types of characters while making sure each character type was included in the password.

Solution: I used the random.choice() function to select characters from each character set before combining them into a password.

Arranging Password Characters

Challenge: Another challenge was to make sure the selected characters weren't always arranged in the same order.

Solution: I used random.shuffle() to randomly rearrange the characters before combining them into the final password.

05. What I Learnt by Developing secureGen

Developing SecureGen was quite an enjoyable and educational experience that helped me improve my understanding of Python, especially when working with strings, lists and Python's random module. I also gained a better understanding of input validation and exception handling, and how these can be used to handle invalid user input.
